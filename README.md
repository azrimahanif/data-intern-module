# AI Knowledge Assistant - 10-Week Data/AI Internship Program

## 🎯 Program Overview

Welcome to the **AI Knowledge Assistant** internship program! This intensive 10-week program is designed to take you from foundational data skills to building a complete AI-powered knowledge management system.

### 🚀 Program Goals

- Master Python programming and SQL for data manipulation
- Build ETL pipelines for data processing
- Develop RESTful APIs using FastAPI
- Implement containerization with Docker and CI/CD
- Work with vector databases for semantic search
- Create RAG (Retrieval-Augmented Generation) pipelines
- Master LLM prompting techniques
- Build AI agents with autonomous capabilities
- Complete a capstone project integrating all skills
- Present your work professionally

### 🛠️ Tech Stack

**Programming & Data:**
- Python 3.9+
- SQL (PostgreSQL/SQLite)
- Pandas, NumPy, Matplotlib
- Jupyter Notebooks

**Backend & APIs:**
- FastAPI
- SQLAlchemy
- Pydantic
- Uvicorn

**DevOps & Deployment:**
- Docker
- Docker Compose
- GitHub Actions
- Environment Management

**AI & Machine Learning:**
- OpenAI API / Anthropic Claude
- Vector Databases (Pinecone/ChromaDB)
- LangChain / LlamaIndex
- Embedding Models (OpenAI, Sentence Transformers)

**Tools & Platforms:**
- Git & GitHub
- VS Code / PyCharm
- Postman / Insomnia
- Jupyter Lab

## 🚀 Getting Started

1. **Clone this repository**
   ```bash
   git clone <repository-url>
   cd internship-auni-2025
   ```

2. **Set up your development environment**
   - Install Python 3.9+
   - Install Docker Desktop
   - Set up VS Code with Python extensions
   - Create a virtual environment

3. **Start with Week 1**
   - Navigate to `week1_python_sql/`
   - Read the README.md for detailed instructions
   - Complete all assignments in the `submission/` folder
